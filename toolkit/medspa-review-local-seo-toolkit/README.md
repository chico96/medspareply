## How to use this toolkit

1. **Read `hipaa-aware-safety-checklist.md` first.** It is the guardrail every
   other file leans on.
2. **Wire up the SOP.** Drop `front-desk-weekly-sop.md` into the team handbook
   and assign an owner. Twenty minutes a week is the entire cadence.
3. **Stock the reply library.** Open `review-reply-templates.md` and copy the
   sections that match your services into your own brand voice doc. Keep the
   placeholders (`[guest first name]`, `[provider]`, `[service]`) explicit so
   the front desk can scan-fill them in under 60 seconds.
4. **Plan four weeks at a time.** Pull from `4-week-content-calendar.csv`
   and `google-business-profile-prompts.md`
   for GBP posts, social snippets, and review-driven content angles.
5. **Use `negative-review-playbook.md` when stakes go up.** 1- and 2-star
   reviews need a different cadence and escalation path — never freelance them.

## Customization placeholders

These appear throughout the templates. Replace globally before posting:

- `[guest first name]` — only when the guest used their first name publicly
- `[provider]` — name a real licensed provider only when the guest already named them
- `[service]` — generic noun (e.g. "facial visit"), not a treatment specifier
- `[clinic name]` — your med spa's brand name
- `[city]` / `[neighborhood]` — for GBP posts, not review replies
- `[practice manager email]` — the private channel for escalations

> Never invent a provider name, a treatment plan, or an outcome. If the guest did
> not say it, you do not say it.
